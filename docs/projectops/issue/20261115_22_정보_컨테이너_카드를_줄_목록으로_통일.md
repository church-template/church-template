- 글만 있는 항목을 박스 카드로 감싸서 주변 줄 목록 섹션과 결이 끊김 (DESIGN.md "한 줄 항목엔 줄 목록" 위반)
- 강조색 반복(배지 6개), 문의 카드와 박스끼리 경쟁 등으로 주인공이 안 보임
- 지금 나와 관련된 정보(다음 예배, 오늘 일정)가 다른 항목과 같은 무게로 보임

🛠️ 해결 방안 / 제안 기능
---

| 화면 | 파일 | 변경 |
|---|---|---|
| `/worship` 특별 예배 | `client/src/components/.../WorshipSpecial.tsx` | 다음 특별 예배 띠(primary-soft) + 연간 줄 목록 |
| `/about/location` 찾아오는 방법 | `client/src/components/.../LocationDirections.tsx` | 카드 스택을 아이콘 줄 목록으로 |
| `/challenges` 목록 | `client/src/components/.../ChallengeList.tsx` | 2열 카드를 줄 목록(기간, 배지+제목, 하루 N장)으로 |
| `/events` 모바일 목록 | `client/src/components/.../EventCalendar.tsx` | EventCard 스택을 아젠다형(왼쪽 날짜 칸 고정, 오늘 표시)으로 |

- 심리 근거: 페이지 안 같은 형태 반복(처리 유창성), 강조는 한 곳만, 날짜·다음 일정 같은 자기 관련 정보를 먼저 노출
- 특별 예배: `SPECIAL_SERVICES`에 날짜 규칙 필드 추가(고정일, n째 주일, 마지막 주일, 부활절), 클라이언트 계산
- 사진 카드(설교, 앨범, 부서), DESIGN.md에 정의된 카드(schedule-card, 문의 폼)는 유지
