🗒️ 설명
---

- `client/next.config.ts`가 `next/image`가 허용할 미디어 주소를 `new URL("/api/media/**", API주소)`로 만든다. 앞에 `/`가 붙은 경로를 주면 API 주소의 경로(`/church/<교회키>`)가 버려진다.
- 그래서 API 주소가 `https://api.example.com/church/<교회키>`이면 허용 주소는 `https://api.example.com/api/media/**`가 되고, 실제 사진 주소 `https://api.example.com/church/<교회키>/api/media/…`와 맞지 않아 `next/image`가 차단한다.
- 해당 화면(로그인한 사람만 보는 곳)이 "문제가 발생했습니다" 오류 화면으로 바뀐다: 갤러리 앨범 카드·사진 목록, 관리 화면의 미디어 선택 창, 미디어 라이브러리. 공지·설교·부서·주보 같은 공개 페이지는 영향이 없다.
- 공유 서버를 쓰는 교회는 모두 API 주소에 교회 키가 들어가므로, 이 템플릿으로 새 교회를 만들면 처음 미디어 관리 화면을 여는 순간 만난다.
- 은샘 프론트는 이미 고쳤다(`mediaRemotePatterns`, eunsaem-frontend 커밋 565986b).

🔄 재현 방법
---

1. `NEXT_PUBLIC_API_BASE=http://localhost:8080/church/dev`로 `pnpm dev`를 띄운다.
2. 관리자로 로그인해 `/mypage/manage/media`를 연다(미디어가 하나 이상 있어야 한다).
3. 오류 화면이 뜬다. 콘솔: `Invalid src prop (http://localhost:8080/church/dev/api/media/…) on next/image, hostname "localhost" is not configured under images in your next.config.js`

✅ 예상 동작
---

- API 주소에 교회 경로가 있어도 없어도 미디어 사진이 정상으로 나온다.
