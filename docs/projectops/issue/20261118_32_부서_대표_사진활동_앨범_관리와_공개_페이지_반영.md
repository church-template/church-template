📝 현재 문제점
---

- 템플릿의 공개 부서 소개 페이지는 사진·소개·활동 사진을 프론트 상수로만 그린다. 관리 화면에서 부서 대표 사진이나 활동 사진 앨범을 바꿀 방법이 없다.
- 공용 백엔드(church-backend #92) 이후 비공개 미디어는 서명 주소로만 열리는데, 템플릿은 서명 주소(`url`)를 다루지 않는다.
- `client/docs/api-docs.json` 사본이 낡아 부서 사진·앨범 칸이 없다.

🛠️ 해결 방안 / 제안 기능
---

- 은샘교회에서 먼저 반영한 부서 사진·앨범 기능을 옮긴다(관련 파일 42개 중 36개가 은샘의 수정 전과 같음).
  - 부서 수정 창에 대표 사진·활동 사진 앨범 칸, 앨범 연결 시 공개 범위 안내
  - 공개 부서 상세: 부서 상수에 `backendId`가 있으면 대표 사진·소개·활동 사진을 API 값으로 덮어쓴다(없거나 API 장애면 상수 그대로)
  - 미디어 서명 주소 대응(`mediaSrc`, 갤러리·마크다운 이미지)
  - 활동 사진 8장씩 "사진 더 보기"
  - API 명세 사본 갱신
- 템플릿에는 교회별 값을 넣지 않는다: `backendId` 칸만 만들고 예시 부서에는 비워 둔다. 정적 예시 사진과 "사역" 메뉴 이름은 그대로 둔다.
