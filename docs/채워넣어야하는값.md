# 교회에서 받아야 할 자료

새 교회 사이트를 만들 때 교회(목사님)께 받아야 하는 사진과 정보 목록입니다. 받은 자료가 들어갈 자리(파일·상수)도 함께 적었습니다.
목사님께 보낼 문서는 [교회-준비자료.docx](교회-준비자료.docx)입니다(한글·Word에서 열림).

- 사진은 휴대폰 원본 그대로 받는다. 크기·비율 조정과 압축은 개발 쪽에서 한다.
- **얼굴이 나오는 교인 사진은 사용 동의를 받은 것만** 받는다. 공개 사이트에 올라간다.
- 설교·공지·일정·주보·갤러리는 사이트를 연 뒤 관리자 화면에서 직접 올린다. 미리 받지 않는다.

## 1. 사진·영상

모든 경로는 `client/public/` 기준입니다. 비율이 코드에 박힌 파일은 상수도 함께 고칩니다.

| 자료 | 수량 | 방향·크기 | 들어가는 곳 |
|---|---|---|---|
| 교회 로고 | 1 | 정사각 512px 이상, 배경 투명 PNG면 좋음 | `onlyLogo.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `og-image.jpg`(1200×630 공유 이미지) |
| 메인 대표 영상 | 1 | 가로, 짧게(무음 자동재생) | `hero.mp4` — 없으면 `church.ts`의 `HERO`를 `type: "image"`로 |
| 메인 대표 사진(영상 첫 화면) | 1 | 가로 | `hero-poster.jpeg` + `HERO_POSTER_ASPECT` (church.ts) |
| 메인 사진 모음 | 4 | 1번 세로·정사각, 2~4번 가로 | `collage-1~4.jpeg` + `COLLAGE_TILES[].aspect` (church.ts) |
| 담임목사님 사진 | 1 | 세로 상반신 | `pastor.jpg` + `PASTOR.image.aspect` (content.ts) |
| 교회 내부 | 5~6 | 가로 | `photos/interior/` + `CHURCH_PHOTOS` (content.ts) |
| 교회 외부 | 5 | 가로 | `photos/exterior/` + `CHURCH_PHOTOS` (content.ts) |
| 연혁 사진 | 연혁 항목마다 1 | 가로 | `history/{id}.jpg` + `HISTORY.items[].media` (content.ts) |
| 부서 대표 사진 | 부서마다 1 | 가로, 큰 사진(화면 전체로 펼쳐짐) | `dept/{slug}.webp` (departments.ts) |
| 부서 활동 사진 | 부서마다 4 | 가로 | `dept/{slug}/1~4.webp` + `gallery` (departments.ts) |
| 약도 (선택) | 1 | 가로 | `location/map-location.png` + `LOCATION.map` (content.ts) — 없으면 지도 링크로 대신 |

장수는 상수 배열만 맞추면 늘리거나 줄일 수 있습니다(교회 내부·외부, 연혁, 부서).

## 2. 기본 정보 — `client/src/constants/church.ts`

| 받을 것 | 예시 | 들어가는 곳 |
|---|---|---|
| 교회 이름(부르는 이름) | 예시교회 | `CHURCH_NAME` |
| 정식 명칭(교단 포함) | 예시교단 예시교회 | `CHURCH_NAME_FULL` |
| 사이트 주소(도메인) — 없으면 새로 구입 | www.example.com | `CHURCH_DOMAIN` |
| 한 줄 소개문(검색 결과에 나옴) | 서울특별시 중구에 위치한 예시교회입니다. … | `CHURCH_DESCRIPTION` |
| 메인 문구 2줄 | 함께 예배하고 함께 자라는 교회 / 예시교회에 오신 것을 환영합니다 | `HERO_CAPTION` |
| 주소(시·도 / 시·군·구 / 나머지) | 서울특별시 / 중구 / 예시로 123 | `CHURCH_ADDRESS_REGION`·`_LOCALITY`·`_STREET` |
| 대표 전화 | 02-000-0000 | `CHURCH_PHONE` |
| 대표 이메일 | contact@example.com | `CHURCH_EMAIL` |
| 설교 등록 때 기본 설교자 표기 | 김은혜 목사님 | `SERMON_DEFAULT_PREACHER` |
| 교회 좌표 (선택) | 위도·경도 | `CHURCH_GEO` |
| 지도 퍼가기 주소 (선택) | 카카오·네이버 지도 iframe 주소 | `MAP_EMBED_SRC` |

## 3. 교회 소개 — `client/src/constants/content.ts`

| 받을 것 | 들어가는 곳 |
|---|---|
| 대표 표어(비전 문장)와 그중 강조할 단어 | `ABOUT.statement`·`statementHighlight`, `VISION.statement` |
| 교회 소개 2문장 | `ABOUT.intro` |
| 로고에 담긴 의미 (있으면) — 색·의미별 제목과 설명 | `ABOUT.symbolism*` |
| 우리의 소망(한 문단) | `ABOUT.hope` |
| 우리의 이야기 2~3문단(설립, 소속, 사명) | `ABOUT.story` |
| 비전 항목 4~6개 | `VISION.points` |
| 메인 사역 3가지(제목 + 한 줄) | `MINISTRIES` |

## 4. 연혁 — `HISTORY` (content.ts)

항목마다 받습니다. 항목 수는 자유입니다.

| 받을 것 | 예시 |
|---|---|
| 날짜(연·월) | 2011년 4월 |
| 제목 | 개척예배 |
| 한 줄 설명 | 가정에서 첫 개척예배를 드렸습니다. |
| 세부 내용 3~4줄 | |
| 의미 한 줄 | |
| 사진 1장 | (1. 사진·영상) |

## 5. 담임목사님 — `PASTOR` (content.ts)

| 받을 것 | 들어가는 곳 |
|---|---|
| 이름, 직함 | `name`, `position` |
| 대표 학력 한 줄 | `degree` |
| 소개 한 문단 | `intro` |
| 인사말 2~3문단 | `greeting` |
| 강조할 인용 한 문장 | `pullQuote` |
| 학력·경력 목록 | `credentials.items` |
| 목회 철학 6개 내외 | `philosophy.items` |

## 6. 예배 — `WORSHIP`·`WORSHIP_SERVICES`·`SPECIAL_SERVICES` (content.ts)

**정기 예배**(예배마다)

| 받을 것 | 예시 |
|---|---|
| 예배명 | 주일예배 |
| 요일·시간 | 주일 오전 11:00 |
| 장소 | 본당 |
| 찬양 시작 시간 (있으면) | 오전 10시 40분 찬양 |
| 설명 3줄 | |

**특별 예배**(예배마다): 이름, 날짜(예: "부활절 주일"), 시간, 설명 한 줄

**처음 오시는 분 안내**: 안내 3줄(주차, 예배 후 교제 등), 예배 장소를 찾는 표시(예: "유리 건물")

## 7. 부서 — `DEPARTMENTS` (departments.ts)

부서마다 받습니다. 부서 수는 자유입니다(메뉴 `navigation.ts`도 함께 맞춤).

| 받을 것 | 들어가는 곳 |
|---|---|
| 부서명 | `name` |
| 소개 한두 문단 | `description` |
| 메인 문구 2줄 | `caption` |
| 소개 제목 + 한 문단 | `intro` |
| 특징 3개(제목 + 한 줄) | `features` |
| 담당자, 모임 시간, 연락처, 모임 장소 | `info` |
| 주요 활동 4개 | `activities` |
| 연간 프로그램 4개(이름 + 한 줄) | `programs` |
| 초대 문구(제목 + 한 문단) | `invite` |
| 대표 사진 1 + 활동 사진 4 | (1. 사진·영상) |

## 8. 오시는 길 — `LOCATION` (content.ts)

- 자가용 안내: 주차 여부, 내비게이션 검색어
- 대중교통 안내: 버스 노선·정류장

## 9. 관리자·서버 — `server/.env`

| 받을 것 | 들어가는 곳 |
|---|---|
| 첫 관리자 이름 | `ADMIN_NAME` |
| 첫 관리자 휴대폰 번호(로그인 아이디) | `ADMIN_PHONE` |
| 첫 관리자 비밀번호 — 문서로 받지 말고 본인이 직접 설정 | `ADMIN_PASSWORD` |

도메인이 정해지면 `CORS_ALLOWED_ORIGIN`(프론트 주소)과 `FILE_BASE_URL`(`https://api.<도메인>/api/media`)도 그에 맞춘다. 나머지 `.env` 값(DB·JWT 비밀값 등)은 개발 쪽에서 만든다 — [setup-new-church.md](../server/docs/setup-new-church.md).

## 정하지 않아도 되는 것

- 이용약관·개인정보 처리방침 — `client/src/constants/terms.ts` 기본 문구를 쓴다. 개인정보 책임자를 따로 적고 싶으면 그때 받는다.
- 디자인 — 기본 파란색. 교회 색을 쓰고 싶으면 대표 색 하나만 받아 primary 토큰 4개를 바꾼다(`.claude/rules/DESIGN.md`).
